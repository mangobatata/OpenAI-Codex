# DSA para principiantes con TypeScript

## Objetivo de este modulo

Entender que es DSA y por que mejora tu forma de programar y de pedir ayuda a Codex.

## Explicacion simple

DSA significa Data Structures and Algorithms: estructuras de datos y algoritmos. Una estructura de datos organiza informacion. Un algoritmo es una serie de pasos para resolver un problema.

## Por que ayuda a programar mejor

DSA te ayuda a elegir si conviene usar un array, un objeto, un `Map`, una pila, una cola, un arbol o un grafo. Tambien mejora tu capacidad de leer codigo, debuggear y explicar problemas.

## Por que ayuda a usar mejor Codex

Cuando sabes nombrar la estructura o estrategia, tus prompts son mas precisos: "usa un Map para contar frecuencias" es mejor que "hace algo para contar".

## Analogias cotidianas

| Concepto | Analogia |
| --- | --- |
| Array | Lista de compras |
| Stack | Pila de platos |
| Queue | Fila de supermercado |
| HashMap | Agenda de contactos |
| Tree | Arbol genealogico |
| Graph | Mapa de rutas |

## Ejemplo TypeScript

```ts
const products: string[] = ["Remera", "Zapato", "Perfume"];

for (const product of products) {
  console.log(product);
}
```

## Que aprender primero

1. Arrays y objetos.
2. Funciones y loops.
3. Map y Set.
4. Stacks y queues.
5. Recursion.
6. Arboles y grafos.
7. Busqueda, ordenamiento y Big O basico.

## Como estudiar sin frustrarse

Hace ejercicios chicos y aplicados a negocios: productos, clientes, turnos, pedidos y stock. No memorices: entende el patron.

## Prompt recomendado

```txt
Explicame este problema DSA como principiante. Primero identifica la estructura de datos adecuada, luego dame solucion TypeScript y finalmente explicala paso a paso.
```

## Mini ejercicio

Crea un array de cinco productos y recorrelo mostrando cada nombre.
