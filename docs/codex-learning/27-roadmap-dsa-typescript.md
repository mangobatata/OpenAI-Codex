# Roadmap DSA en TypeScript

## Objetivo de este modulo

Seguir un plan de 8 semanas para aprender DSA desde cero.

## Semana 1: Fundamentos TypeScript para DSA

Objetivo: escribir codigo basico con confianza. Temas: variables, arrays, objetos, funciones, loops y condicionales. Ejercicio: listar productos. Mini proyecto: calculadora simple de subtotal.

## Semana 2: Arrays y strings

Objetivo: recorrer y transformar listas. Temas: buscar, filtrar, transformar y contar frecuencias. Ejercicio: encontrar producto por nombre. Mini proyecto: buscador simple de catalogo.

## Semana 3: HashMaps y Sets

Objetivo: usar busqueda rapida. Temas: objetos como diccionarios, `Map`, `Set`, duplicados. Ejercicio: detectar SKUs repetidos. Mini proyecto: indice de clientes por WhatsApp.

## Semana 4: Stacks y Queues

Objetivo: modelar orden de entrada/salida. Temas: pila, cola, undo/redo y turnos. Ejercicio: fila de espera. Mini proyecto: cola de atencion de clientes.

## Semana 5: Recursion

Objetivo: resolver problemas que se repiten sobre partes mas pequenas. Temas: caso base, llamada recursiva, errores comunes. Ejercicio: suma recursiva. Mini proyecto: recorrer categorias anidadas.


## Bloque especial: Patrones de resolucion de problemas

Estudiar este bloque despues de arrays, strings, HashMaps y Sets, y antes de estructuras mas avanzadas como arboles y grafos.

Temas:

- Frequency Counter.
- Multiple Pointers.
- Sliding Window.
- Divide and Conquer.

Objetivo: aprender a reconocer la forma del problema antes de escribir codigo. Ejercicio: resolver un caso de negocio con cada patron. Mini proyecto: agregar patrones al mini inventario.

## Semana 6: Arboles

Objetivo: entender jerarquias. Temas: nodos, raiz, hijos y recorridos. Ejercicio: menu de categorias. Mini proyecto: arbol de categorias de tienda.

## Semana 7: Grafos

Objetivo: entender conexiones. Temas: nodos, conexiones, rutas, mapa simple. Ejercicio: ciudades conectadas. Mini proyecto: rutas de delivery simuladas.

## Semana 8: Ordenamiento, busqueda y Big O basico

Objetivo: pensar eficiencia. Temas: busqueda lineal, busqueda binaria, sort y complejidad basica. Ejercicio: ordenar productos por precio. Mini proyecto: ranking de productos vendidos.

## Prompt recomendado

```txt
Estoy en la semana 3 del roadmap DSA. Dame 3 ejercicios con solucion TypeScript sobre Map y Set aplicados a un negocio local.
```
