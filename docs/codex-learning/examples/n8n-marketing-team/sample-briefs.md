# Briefs simples

## Reel de producto

Objetivo: mostrar una prenda en uso real. Formato vertical. Escenas: detalle, combinacion casual, combinacion elegante. CTA: escribir por WhatsApp.

## Post de confianza

Objetivo: reducir dudas antes de comprar. Visual: pedido preparado, bolsa, mensaje de confirmacion. Copy: claro y cercano.

## Historia de promocion

Objetivo: activar consultas rapidas. Visual: producto destacado, precio o beneficio, sticker de pregunta. CTA: "Responde esta historia".
