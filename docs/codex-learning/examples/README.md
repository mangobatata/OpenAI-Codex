# Ejemplos

Estos ejemplos son educativos y simulados. No conectan cuentas reales, no envian mensajes reales, no crean eventos reales y no gastan dinero.

- `n8n-turnos/`: workflow exportable demo de agente de turnos.
- `n8n-marketing-team/`: workflow exportable demo de Marketing Team IA.
- `agents-md-example/`: ejemplo profesional de instrucciones de proyecto.
- `bootstrap-scripts/`: scripts educativos de preparacion.
- `dsa-mini-inventory/`: proyecto final DSA en TypeScript.
