# Proyecto DSA final: mini inventario en TypeScript

## Objetivo de este modulo

Construir un mini sistema de inventario usando arrays, objetos, `Map`, funciones, busqueda, filtros, ordenamiento, conteo y validaciones simples.

## Estructura sugerida

```txt
examples/dsa-mini-inventory/
README.md
package.example.json
src/index.ts
src/inventory.ts
src/inventory.test.ts
```

## Funciones sugeridas

```ts
addProduct()
findProductBySku()
updateStock()
getLowStockProducts()
getTopSellingProducts()
calculateInventoryValue()
```

## Como practicar con Codex

```txt
Ayudame a implementar el mini inventario por fases. Primero revisa la estructura, luego implementa addProduct y findProductBySku con tests simples. No agregues dependencias sin preguntarme.
```

## Checklist de comprension

- Uso arrays para listas.
- Uso Map para busqueda por SKU.
- Uso filtros para stock bajo.
- Uso sort para mas vendidos.
- Uso reduce para valor total.
