# Computer Use

## Objetivo de este modulo

Saber cuando conviene que Codex controle una app visual y cuando es mejor trabajar con archivos.

## Explicacion simple

Computer Use permite interactuar con navegador o apps visuales: mirar una UI, hacer clicks, detectar solapamientos o probar un flujo. No reemplaza lectura de codigo ni tests.

## Analogia cotidiana

Leer archivos es revisar planos. Computer Use es caminar por el edificio terminado.

## Conceptos clave

| Caso | Usar Computer Use |
| --- | --- |
| Revisar dashboard visual | Si |
| Refactor de backend | No |
| Probar formulario | Si |
| Editar Markdown | No |

## Ejemplo practico

```txt
Abri la app en el navegador, revisa visualmente el dashboard, detecta solapamientos, no hagas compras ni acciones destructivas.
```

## Como se usa paso a paso

1. Levanta la app local.
2. Define paginas a revisar.
3. Aclara acciones prohibidas.
4. Pide evidencia: screenshots, errores, pasos.
5. Corrige y vuelve a verificar.

## Buenas practicas

Usa datos de prueba. No hagas compras, envios reales ni cambios irreversibles. Pedile que no cruce pantallas sensibles.

## Errores comunes

Usarlo para tareas que se resuelven mejor leyendo codigo. No definir limites.

## Prompt recomendado

```txt
Usa Computer Use solo para revisar la UI. No envies formularios reales ni cambies configuraciones de cuenta.
```
