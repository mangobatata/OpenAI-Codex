# Curso practico de Codex Desktop

## Que es este curso

Esta guia ensena Codex desde cero con un enfoque practico-profesional: contexto, prompts, permisos, terminal, AGENTS.md, plugins, Skills, MCPs, Computer Use, automatizaciones, worktrees, bootstrap, uso responsable de tokens/costos y casos con n8n.

## Como estudiarlo

Avanza en orden. Lee un modulo, ejecuta el mini ejercicio y abre un chat separado de Codex para practicar sin mezclar objetivos. Para tareas largas, crea resumenes de continuidad antes de cambiar de tema.

## Orden recomendado

1. Contexto y compactacion.
2. Prompts y voz.
3. Permisos, guardrails y terminal.
4. AGENTS.md.
5. Metodo de trabajo.
6. Plugins, Computer Use, Skills, MCPs y subagentes.
7. Automatizaciones, worktrees y bootstrap.
8. Casos n8n.
9. Camino de n8n a SaaS.
10. Seguridad, costos, tokens y uso responsable.

## Regla global de eficiencia

Durante todo el trabajo, usa Codex con bajo consumo de contexto y tokens: tareas pequenas, rutas especificas, logs minimos, respuestas enfocadas, resumenes de continuidad, revision incremental y no leer todo el repositorio sin necesidad.

## Herramientas que vas a aprender

Codex Desktop, ChatGPT Work, Chat normal, terminal integrada, archivos locales, plugins, Skills, MCPs, Computer Use, automatizaciones, Git worktrees, n8n, Google Sheets, Google Calendar y flujos simulados con WhatsApp.

## Como practicar

Usa proyectos pequenos. Pedi primero inspeccion, luego plan, despues implementacion y finalmente verificacion. No conectes cuentas reales ni ejecutes acciones externas hasta entender permisos, riesgos y revision humana.

## Chats separados

Usa un chat para estudiar, otro para practicar comandos, otro para documentacion y otro para automatizaciones. En cada chat, deja claro el objetivo, rutas permitidas y criterios de verificacion.
