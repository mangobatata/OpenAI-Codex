# Las cinco primitivas practicas

## Objetivo de este modulo

Usar un metodo simple para trabajar con Codex sin saltar directo a cambios fragiles.

## Explicacion simple

Las cinco primitivas son habitos: leer, entender, planificar, editar, verificar y resumir. Convierten una tarea ambigua en un flujo controlado.

## Analogia cotidiana

Antes de reparar una maquina: miras, entendes, decidis, reparas y probas.

## Conceptos clave

| Primitiva | Que significa | Prompt |
| --- | --- | --- |
| Leer | Inspeccionar repo | "Revisa archivos relacionados" |
| Entender | Explicar estado | "Decime como funciona" |
| Planificar | Definir pasos | "Propone plan breve" |
| Editar | Cambiar codigo | "Implementa solo esto" |
| Verificar y resumir | Probar y cerrar | "Ejecuta tests y resume" |

## Ejemplo practico

```txt
Primero inspecciona.
Luego propone.
Despues implementa.
Luego ejecuta pruebas.
Finalmente resume cambios y riesgos.
```

## Como se usa paso a paso

1. Pide inspeccion.
2. Pide explicacion del flujo.
3. Aprueba o ajusta plan.
4. Deja que edite.
5. Revisa verificaciones y diff.

## Buenas practicas

En tareas pequenas, el plan puede ser una frase. En tareas grandes, pedi checklist.

## Errores comunes

Editar antes de leer. Probar solo manualmente. No resumir riesgos.

## Prompt recomendado

```txt
Trabaja con el metodo leer, entender, planificar, editar, verificar y resumir. Mantene los cambios acotados.
```

## Mini ejercicio

Toma una feature pendiente y escribi como se veria en estas cinco primitivas.

## Checklist de comprension

- Puedo dividir tareas.
- Se pedir verificacion.
- Se evitar cambios impulsivos.
